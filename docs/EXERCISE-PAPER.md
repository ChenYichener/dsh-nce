# 练习卷（可填写的试卷）

单课页面最下方的「练习」区，从只读的题目列表改成了**可填写的试卷**：填空处直接变成输入框，简答/改写题在题目下方给一条答题线，
写完点「批改整卷」由 **AI 老师逐题批改整卷**（没有默认模型时自动退回系统判分）、给出点评和参考答案，
判错的题可以手动改判。答案随写随存，换页面、切课、重启 DSH 都不会丢。
「练习」区从上到下是：作业清单折叠卡、课堂跟读折叠卡、完整的可填写练习卷（卷内集成 AI 整卷批改）。

本文说明数据从哪来、怎么判分、草稿存在哪、以及已知的限制。纯判分引擎在 `src/client/10-paper-engine.js`，
UI/草稿持久化/PDF 集成在 `src/client/30-paper-ui.js`。

## 1. 页面结构

- **卷头**：课号 + 中英标题、已答/总题数、可判分题数、例句数、自动保存时间、整卷进度条；
  批改后显示 **得分**：AI 批改时是 **AI 判对 / 总题数**（含未答），退回系统判分时是 `正确 / 可判分`；
  下面是正确/近似/错误/未答统计。
  - 「批改整卷」：**一次点击统一批改整卷**——把全部已作答的题（课文书面练习 + 语法练习册）交给当前 profile 的默认模型
    逐题批改，返回「正确 / 近似 / 错误 + 中文点评 + 参考答案」；得分统一按 AI 判词算，判对/判错可以手改。
    再点一次变成「收起批改」隐藏红笔与答案；没有默认模型或 AI 失败时自动退回系统判分，并在卷头黄字说明。
  - 「AI 补批 N 题」：批改后有题还没有 AI 判词（改过答案、AI 漏批、上次失败）时出现，只补发这些题。
  - 「显示全部答案」：不批改也能先对答案；按大题「对答案」可只展开一组。
  - 「清空答案」：两段式确认，第二次点击才清空（清答案、改判记录和批改状态）。
  - 「标记练习完成」：批改后出现，把本课学习步骤里的「练习」打勾（写入宿主 SQLite 进度，与单课页的 3 步进度同步）。
  - 「预览 PDF」：打开 A4 分页预览弹窗（先本地渲染出真实 PDF，再逐页显示）；弹窗里点「下载 PDF」直接下载
    浏览器本地生成的 PDF 文件（不联网、不经过 host、不弹打印对话框）；「打印」走打印窗口兜底。
  - 「打印整卷」：调用浏览器打印（可另存为 PDF）；打印样式隐藏导航/吸顶锚点条/按钮、保留得分与红笔标记，展开滚动容器，整卷按 A4 分页。
- **大题**（每个练习组一张卡）：中文序号 + 原书题号（`I.` / `A` …）+ 中英题目要求 + 题目数量/已答/正确数。
  课文练习的「示范」、练习册的词框 `EXAMPLE`、表格原样展示。
- **小题**：
  - 有 `___` 的题：空位内嵌输入框，按原句排版；单击即可填，`Enter` 跳到下一个空。
  - 无空的题：题目下方一条整行输入框（改写、问答、抄写）；个别书上只有编号作答行的题（题干为空），
    显示「（按本组例题 / 表格要求作答）」提示 + 作答框 + 参考答案，不编造题干。
  - 书上的**worked example**（示例行已带答案、答案册里没有对应条目）：直接静态展示，标「示例」，不算题目、不判分；
    印刷示例里带 `___` 的（答案册从第 2 题才给答案）同样识别为示例，不会变成「填空但无参考答案」的怪题。
  - 字母小题（`a.` `b.` `c.` …）：拆成独立小题，每题一个输入框和一份参考答案。
  - 一题多问（书上把 2–3 个问题排在一个题号下、每个问题一条答题线，如 lesson 5 II、10 I、31 I、71 III）：
    题目按原书拆成多行，每行右侧一个独立输入框；有答案册时逐行给答案（`No, it isn't.` / `Yes, it is.`），
    全部答对才算这道题对，逐行显示 ✓/✗。示例题按书上的 Q/A 成对静态展示。
  - 问答/对话类（`Ask and answer …`、`Make dialogues …`，如 lesson 19 I、32 II、42 I、44 I）：
    按答案册的印刷行拆成「问句行 / 答句行」，每行一个输入框（lesson 42 I 一道题就是 问/答/问/答 4 行）；
    题干是 cue 的题在左侧显示 cue，其余答题行留空、按行给「问句/答句」提示。
  - 印刷示例：答案册从第 N 题开始给答案时，前面的 1…N−1 题按书上的 worked example 静态展示；
    同一题号下答案从 b/c 开始时，前面的 a/b 小题也按示例处理（如 lesson 7 III、32 I、109 II）。
  - 表格/听写类题目（源数据里没有 `items`，只有表格或「Dictation.」）：按题目里的数量（“write eleven sentences.” / “9 句话”）
    生成编号自由作答行，没有固定答案，写完自评。
  - **表格题**：源数据 `sections[].table`（二维数组，如 lesson 110 的信息表/成绩表）渲染成原书表格，
    空题干 + 参考答案的编号作答行单独成行（不再把表格压成一行文字）。
  - **词框**：`sections[].wordBox`（如 `Use the words in the box…`）渲染成带边框的词卡框；没有 wordBox 时退回 `example` 行。
  - 配对题（`Match … Column A with Column B` / 「搭配」「连线」）：按原书版式渲染成 **A/B 两栏**，
    A 栏每题后面一个字母输入框、B 栏列出带字母的选项；答案册的「题号-字母」键用来逐题自动判分
    （可填多个字母，如 `e, f`；也可直接填 B 栏单词；填不全标「近似」），仍保留手动判对/判错。
    旧数据没有结构化 matching 时退回「可填 + 配对参考答案面板」。
- **批改后每题**：左侧红/绿标记 + 状态胶囊（正确/错误/近似/未答/待批/自评）+ AI 点评与参考答案；
  右侧「判对 / 判错」可覆盖自动判定——没有标准答案的题、或者你觉得参考答案本身有误时，用它改判。

## 2. 题目和答案从哪来

| 来源 | 数据字段 | 有答案吗 | 处理方式 |
| --- | --- | --- | --- |
| 课文书面练习 | `lesson.exercises[]` | 一般没有 | 有空的题可填、自评；`Copy these sentences.` 这类抄写题以**原句作为参考答案**，可自动判；表格/听写类自动生成自由作答行 |
| 语法练习册 | `lesson.gwb.sections[]` | 有答案册 | 有 `matching`（A/B 两栏 + 题号-字母答案键）按字母判分；有 `table`/`wordBox` 原样渲染；`example`/印刷示例静态展示 |
| 语法练习册 | `lesson.gwb.sections[]` | 有，在 `lesson.gwb.answers[]` | 按大题 label + 小题号/字母匹配；可自动判，缺口自评 |

答案块解析（`PaperParseAnswers`）处理了 OCR 数据里的常见噪声：

- `2. My name is Ann Scott.` → 第 2 题整句答案；
- `2. b. No, they aren't.` / 后续 `c. …` → 第 2 题的 b、c 字母小题；
- `I0. is, comes, speaks, is` → 修复成第 10 题；`II.` → 第 11 题；
- 答案字符串里夹带换行 → 先按行拆开再解析；
- 斜杠的语义按书写方式判断（源数据里同一个 `/` 有两种用途）：
  - `" / "`（两边都有空格）通常是「同一答案的不同写法」，任一种都算对（例：`This is not my umbrella. / This isn't my umbrella.`）；
    多空题且斜杠数与空位数一致时（例 `it is / it isn't` 对应两个空）按顺序逐空判分；
  - 裸斜杠 / 只有一边有空格的斜杠大多是 OCR 的**换行**（例：`No, she isn't. /She's in the kitchen. …`），
    拆成多个「必答部分」，全部写出才算对；前面很短的对题提示词（如 `umbrellas/Which is…` 里的 umbrellas）会自动丢弃；
  - `He/She`、`I/We`、`a/an` 这类词内斜杠展开成两种完整写法，都算对（OCR 的 `1/We` 会还原成 `I/We`）；
  - `Yes, …/No, …` 视为同一题两种可接受的回答；
  - 答案以省略号结尾时（`I'm a/an...`）允许在答案后面继续补全内容。
- 同一题有多行答案：几乎相同的多行（同一答案的不同写法/OCR 重复）merge 成一组多解，任一种算对；
  差别较大的多行（问答两句、连续变换）拆成多个必答部分，全部命中才算对；纯中文注释行展示但不判分；
- 配对题（Match / 搭配 / 连线）的「题号-字母」答案表用于逐题判分：A 栏每行填一个或多个字母（也可填 B 栏单词），
  字母集合与答案键一致算对、部分命中算「近似」、没有命中算错；答案键不唯一时保留原书的说明文字；
- 同一 item 里重复出现同一个字母小题（OCR 把两批题目并进一个 item）→ 第一处保留答案、重复处改为自评，
  题目编号显示成 `2c′` 之类，避免两行同名。

## 3. 判分规则

比对前先做归一化（`PaperNorm`）：小写、统一弯引号、展开常见缩写（`isn't → is not`、`it's → it is`、
`can't → can not`…）、去掉标点、折叠空白。所以大小写、句号、缩写写全/写缩都算对。

多行答案块会先自动分组（`PaperBuildParts`）：

- **几乎相同的多行**（同一答案的不同写法、OCR 重复、`1/` 与 `I/` 之类）视为一组「多解」，任一种写法都算对；
- **差别较大的多行**（问句 + 答句、连续几句改写）视为多个「必答部分」，需要全部命中；
- 纯中文的注释行（如「注：答案不唯一…」）仍然展示，但不参与判分；
- 同一小题里重复出现的字母小题（OCR 把两批题目并进一个 item）只第一处保留答案，后一处交给自评，避免显示错位答案。

对每个「必答部分」逐一匹配（`PaperPartRank`）：

1. 归一化后完全相同 → 对；
2. 多必答部分时，作答里包含每一个部分 → 对；
3. 填空类允许「片段」：只看**空位所在那一行**的题干预词——这些词要大部分出现在参考答案里，且填的内容覆盖
   「参考答案中该行没出现的部分」的 ≥ 60% → 对
   （例：「After Jimmy had washed and dressed, ___」填 "he had his breakfast" 算对，填 "breakfast" 或题干里的词不算）；
   空位单独成行（如 `B: ___`）时要求整句作答，不接受片段；
4. 词重合度 ≥ 0.9 → **近似**（黄色 ≈，不算对也不算错，看参考答案自己判断）；
5. 其它 → 错。

整卷判分时，每题按「填空内容按顺序拼起来 / 整行输入」参与比对；部分空没填 = 未答。

**得分口径（统一）**：点「批改整卷」后，**整张卷由 AI 老师一个口径判分**：
`得分 = AI 判对题数 / 总题数`（总题数 = 全部非示例题，含未作答；所以没做完时分会偏低，和老师批卷一致）。
手动「判对 / 判错」覆盖 AI 判词并同步改分；未作答的题不浪费 AI 调用，只记「未答」。
只有 AI 不可用 / 失败退回系统判分时，才使用旧口径 `自动判对 / 可判分题`，并在卷头黄字说明原因；
此时没有答案册的题显示「自评」，可以在卷内用 `判对 / 判错` 记录你自己的判断。

**为什么还要手动改判**：答案册是 OCR 整理的，个别答案/题号可能错位；另外有些题有多种正确写法而数据只收了一种。
自动判分只做「批改初稿」，最终以你对着参考答案的判断为准，「判对/判错」会覆盖自动结果并计入右侧统计。

### AI 老师批改（整卷统一批改）

每次点「批改整卷」都会把**全部已作答的题**交给当前 profile 的默认模型（不需要 API Key）：
课文书面练习没有答案册，由 AI 老师按题意/示范判；语法练习册、配对题这类有答案册的题，
会把**答案册参考答案一并放进提示词**，要求 AI 以答案册为准，避免同一张卷出现两套判分口径。

- 发给模型的只有：课号 + 课名、题干、本组上下文（书上示范 / 词框 / 表格 / 配对题 B 栏选项）、
  答案册参考（有的话）、你的答案；不发送进度、单词卡等其它数据。
- 模型逐题返回「correct / close / wrong」+ 一句中文点评 + 参考写法；每题下方显示 AI 判词与点评，
  没有答案册的题还会显示 AI 给的参考写法（有答案册的题直接显示答案册答案）。
- **得分只有一个**：`AI 判对 / 总题数`，未作答算未答；「判对 / 判错」可改任何一题的判词并立刻改分。
- 结果随草稿存进同一个 localStorage key（`ai` 字段）；改某题答案会自动作废该题的 AI 判词，
  批改后卷头会出现「AI 补批 N 题」，只补发这些题；全部有判词后不再出现。
- 题多时按 **20 题一批**顺序请求，按钮上显示 `AI 批改中 40/89…`；90 秒超时、同参数 10 分钟内存缓存。
- AI 不可用（profile 没默认模型 / 超时 / 解析失败）时**不阻断批改**：自动退回系统判分（只覆盖有答案册的题，
  没有答案册的题显示「自评」），卷头黄字提示失败原因；修好后点「AI 补批」重新用 AI 判。
- 解析对模型输出很宽容：行分隔 JSON / 外层数组 / ```json 代码块 / 中文判定词（正确、近似、错误）/
  带字段别名（题号、判定、点评、参考答案）/ 模型用 1、2、3 编号而不是 id（按顺序回退）都能识别；
  被截断的外层 JSON 里已经完整的题也会保留。解析失败时宿主会自动再让模型「把上次输出重排成规定格式」一次。
- 失败时卷头提示：没有默认模型（503）、超时（504）、模型没返回正文（502，会带 finish 原因，如 `tool-calls` / `length`）、
  两轮都无法解析（502，会显示模型输出开头）；两轮解析失败的原始输出会存到
  `~/.dsh/dsh-nce/ai-grade-last-failure.json` 方便排查。
- 模型偶尔只批一部分（比如 20 题里返回 16 题）：已批的会先落进草稿，卷头黄字提示「AI 只批改了 x/y 题」，
  再点「AI 补批」只发没批的题。
- 隐私：结果只存本机浏览器草稿，不写 `~/.dsh/dsh-nce/nce.sqlite`；是否把作业发给模型由你点按钮决定。

## 4. 草稿保存与清除

- 存储：浏览器 `localStorage`，每课一个 key：`dsh-nce/paper/v1/lesson-<课号>`。
- 结构：`{ version, updatedAt, graded, answers, marks, revealed, ai }`
  - `answers`：`<题id>#a`（整行作答）或 `<题id>#b0`、`#b1`…（第 n 个空）→ 文本；
  - `marks`：`<题id>` → `right` / `wrong`，手动改判（覆盖 AI 判词）；
  - `revealed`：大题 key（`ex:0` / `gwb:1`）→ 是否展开参考答案，另加 `stray` 用于「其他参考答案」；
  - `ai`：`<题id>` → `{ verdict, comment, answer }`，AI 老师的判词/点评/参考写法（改答案会作废对应题）。
- 写入时机：第一次真的输入/改判/展开答案时才创建 key（只打开试卷不会产生空草稿）；之后每次修改同步写入，
  卷头显示「已自动保存 HH:MM」。注意这是同步写，不防抖，但一张卷的草稿只有几 KB。
- 写入失败（隐私模式 / 存储配额满）时，卷头会显示红色的「自动保存失败」，而不是继续假装已保存。
- 「清空答案」除了清空界面，也会删掉本课 localStorage key。
- 题 id 形如 `gwb:0:12`、`gwb:0:12:b`（来源:大题序号:小题序号[:字母小题]），不随课号变化；
  **重建 `data/` 改变题序时，旧草稿可能对不上**，此时用「清空答案」重做即可。
- 清除：卷内「清空答案」只清本课；清全部练习草稿可在浏览器控制台
  `Object.keys(localStorage).filter(k => k.startsWith('dsh-nce/paper/')).forEach(k => localStorage.removeItem(k))`。
- 练习答案**不进** `~/.dsh/dsh-nce/nce.sqlite`（宿主 API 不参与），所以 SQLite 备份/换设备不会带走草稿；
  只要不清浏览器站点数据就不会丢。

## 5. 键盘与交互

- `Enter`：光标跳到本卷下一个输入框（`Shift+Enter` 反向，最后一个输入框按 `Enter` 会移开焦点）；
  这样填空可以一路敲下去，不用鼠标点。
- 所有输入框 `autocomplete=off`、`spellcheck=false`，避免宿主/浏览器拼写波浪线干扰。
- 窄窗口（≤720px，按试卷自身宽度判断，受左侧课程列表影响）卷头自动纵向堆叠，判分按钮换行，仍可直接填写。
- 打印 / PDF 时隐藏导航、操作按钮、保存提示和自评按钮，保留得分卡片与红绿批改标记；
  题目行、表格行、配对行不跨页断开（大题允许跨页），A4 页边距由 `@page` 控制，可以直接打印成纸质卷。

## 6. 已知限制

- 课文书面练习（约 72 课有）**没有答案册**：统一由「批改整卷」的 AI 老师按题意/示范判分并给参考写法；
  没有默认模型或 AI 失败时退回系统判分，这部分题只能自评（得分只统计有答案册的题）。
  表格造句/听写这类本来就没有标准答案的题，给出自由作答行（数量取自题目要求），同样纳入自评。
- 自动判分是启发式：近似/多解/语序差异可能误判，所以永远保留「判对/判错」。
  参考答案本身来自 OCR，个别题号错位（例如答案块里混入了下一题的答案）也可能让批改整体偏一点。
- 印刷示例的判定依赖答案册：答案从第 2 题开始 → 第 1 题是示例；答案从 3–5 题开始 → 前几题都按示例处理；
  字母小题答案从 b 开始 → a 也按示例处理。**没有答案册的自评大题不做这种推断**（题目保持可填），
  所以极少数带示例的自评题会多出一个输入框，按书上示例直接对照即可。
- 批改状态、答案都只在当前浏览器；不同 DSH Web 端口（origin 变了）草稿不互通。
- 源数据里的 `/` 既当换行又当「或」，判分只能按书写形式猜：裸斜杠按换行处理、带空格的按多解处理；
  仍有个别题会偏严或偏松，用「判对/判错」覆盖即可。
- 自动判分只覆盖有答案的题（全册约 3400 道）；没有答案册的课文练习、部分书本身缺答案的小节只能自评。
- 一题多问/问答类现在按答题线拆成多行输入；仍按单题一个输入框的是书上本来就只有一条答题线的题
  （如 lesson 12 II、24 II、98 II、128 II：两个问题共用一条线），以及整段 cue 合并题（lesson 43 I–III、22 II 等），
  这些题需要自己把多部分写全（用 ` / ` 分隔）。
- lesson 32 II 的 b–f 在书上是「左问句 / 右答语」同行双栏空白行；插件按 6 行纵向展示，语义一致，
  但不做左右分栏还原。
- 个别长对话/词库版式（如 lesson 75 III、119 II 日记）按文本行展示，不追求逐行还原书页图片。
- PDF 是**图片型**（每页 JPEG，约 235 DPI）：忠实还原版式，但文字不可选中/搜索；若需要可复制文字的 PDF 需要另做文字排版导出版。
- PDF 在浏览器本地生成（`src/client/09-pdf-export.js`）：不依赖 host、Chrome 进程或网络，首次导出约 150–300ms、0.6–1.3 MB；
  页面特别长时自动降低栅格倍率。失败时可用「打印整卷」在打印对话框里另存为 PDF。
