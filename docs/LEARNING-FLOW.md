# 单课学习页：视频 → 课文 + 单词 → 语法 → 练习

每一课现在只有**一页**：从页头往下滚动，依次经过 视频（默认收起）→ 课文 + 单词 → 语法 → 练习。
课文直接合进这一页；学完整课不用在几个页面之间来回点。
学习步骤也收敛为 3 个：**单词 / 语法 / 练习**。

## 1. 为什么合并

- **减少点击**：以前同一课拆在多个页面里，现在点开一课就是全部内容；页头下方的吸顶锚点条可以一步跳到目标区块。
- **上下滚动就能看完整课**：上课顺序（看视频 → 读课文背单词 → 看语法笔记 → 做练习）就是页面从上到下的顺序，
  不会因为切页丢掉上下文。
- **课程页只放学习内容**：单词/句子的复习回到「记忆卡」页和练习卷里完成；原来的回忆类页面已移除。
- **进度模型更简单**：5 个学习步骤减为 3 个（`words` / `grammar` / `exercise`），左侧课程列表的状态下拉框、
  各区块的步骤开关和左侧课程列表的步骤小点共用同一份进度。

## 2. 页面结构

```
┌ 页头：上一课 / 第 N 课 / 下一课，英文标题、中文标题、生词数 · 对话句数 · 课本页，
│       状态徽章（已学完 / 已完成 1/3，只读）
├ 吸顶锚点条：跳到 视频 · 课文 · 单词 · 语法 · 练习（点击平滑滚动）
├ 视频：默认收起成一行，点「展开视频」再内嵌播放（B 站合集分 P / 自定义链接）
├ 课文（左栏）                              │ 单词（右栏）
│ 本课问题 + 对话逐句（点整句或喇叭朗读）    │ 生词表：音标 / 词性 / 释义、喇叭朗读、
│ 参考译文（可折叠）                         │ ★ 加入记忆卡、去记忆卡、待复习标记
├ 语法：课文注释 + 课堂笔记（语法 / 生词 / 练习 / 作业块）
└ 练习：作业清单（折叠）+ 课堂跟读（折叠）+ 可填写的练习卷（含 AI 老师整卷批改）
```

页面就到这里结束：没有页尾区块，学习状态在左侧课程列表每行的下拉框里切换，上一课/下一课在页头。

### 2.1 页头

- 页头右上角「上一课 / 下一课」按课号切换（`< 第 N 课 >`），只换当前课、仍然停在课程页。
- 课号 + 英文标题 + 中文标题，下面一行是 **生词数 · 对话句数 · 课本页**。
- 状态徽章是**只读**的：已学完显示「已学完」，否则显示「已完成 X/3」（3 个学习步骤完成了几个）。
- 状态修改不在这里：**左侧课程列表每行右侧的下拉框**直接选「未学习 / 学习中 / 已学习」，
  简单快捷；选「已学习」会把单词/语法/练习三步一起勾上。

### 2.2 吸顶锚点条

页头下方是一条吸顶的 **视频 / 课文 / 单词 / 语法 / 练习** 锚点条（`LessonAnchorBar`）：
页面往上滚时它停在顶端，点任意一项平滑滚动到对应区块；区块本身带 `data-lesson-anchor`，滚动时留出锚点条高度，
不会被挡住。页面容器很窄时（≤800px，例如课程页切成单列表布局）锚点条改为随页面滚动，避免跟顶部的「← 课程列表」返回条重叠。旧存档或其它深链带来的锚点也会在课程渲染完成后自动滚过去。

### 2.3 视频（默认收起）

- 视频区默认**收起**，只占一行标题；点区块右侧「展开视频」才会挂载播放器，再点「收起视频」收起。
  锚点条的「视频」也会在滚过去的同时自动展开，不用先点两次。
- 展开后默认播放内置 B 站合集（「胶学 x 刘羽Leo」）里本课对应的分 P；一课有多个分 P 时用上方标签切换（标了时长）。
- 「改用自定义链接」可以粘贴本课自己的 B 站 / YouTube 链接，只保存在本地进度里；
  随时「恢复默认 B 站视频」。
- 合集里没有匹配分 P 时显示空态，并给「在 B 站搜本课 / YouTube 搜本课」入口。

### 2.4 课文 + 单词（双栏）

两块内容并排成左右两栏（`课文` 左栏宽一些，`单词` 右栏）；页面容器变窄时（≤640px）自动上下堆叠，
不依赖窗口宽度判断，所以嵌在左侧课程列表右边时也能正确换行。

**课文**（左栏，`LessonTextSection`）：

- 本课问题（Question，英文可点喇叭朗读，带中文）；
- 对话逐句：英文 + 中文、说话人、序号。**点整句任意位置**（或聚焦后按 Enter / 空格）朗读这一句，
  右侧喇叭按钮也可以单独点；不用精准点小喇叭。
- 参考译文默认折叠，点「显示参考译文」展开；如果这一课大部分句子还没有中文翻译，会自动展开。
- 区块标题右侧显示「N 句 · 点整句或喇叭朗读」。

**单词**（右栏，`LessonWordsSection`）：

- 生词表：单词、音标、词性、中文释义；每个词有喇叭朗读；到期卡片会标「待复习」。
- ★ 按钮把单词加入/移出记忆卡收藏；「去记忆卡」跳到记忆卡复习页。
- 区块标题右侧是单词步骤的开关（「标记完成 / 已完成」）。

### 2.5 语法

语法区块（`LessonGrammarSection`）把两处内容放在一起：

- **课文注释**：按编号排列的英文注释 + 中文解释，英文可点读；
- **课堂笔记**：来自《课堂笔记&课后练习》PDF 的分页笔记，按块展示「语法 / 生词 / 练习 / 作业」。
  语法、生词块直接展开（生词块可点读）；练习、作业块是折叠卡，点开才显示。
- 区块标题右侧是语法步骤的开关。

### 2.6 练习

练习区块（`LessonExerciseTab` 等）从上到下：

1. **作业清单**（`LessonHomeworkChecklist`）：把课堂笔记里该课的 `homework` 块拆成一条条任务（去重、
   具体任务排在「讲解/回忆」类通用任务前面），逐项勾选；勾选状态存在本机
   `localStorage` 的 `dsh-nce/homework/v1/lesson-<课号>`。没有作业数据的课不显示这张卡。
2. **课堂跟读**（`LessonPracticeBlocks`）：课堂笔记里的 `practice` 块，按块折叠，每行英文带喇叭，适合跟读模仿。
3. **练习卷**：完整的可填写练习卷（填空题内嵌输入框、配对题 A/B 两栏、表格题、词框、参考答案、手动改判）。
   写完点「批改整卷」交给当前 profile 的默认模型当 AI 老师逐题批改；没有默认模型时退回系统判分。
   答案随写随存（`dsh-nce/paper/v1/lesson-<课号>`），批改后可「标记练习完成」，也可以预览/下载 PDF、打印整卷。
   细节见 [EXERCISE-PAPER.md](EXERCISE-PAPER.md)。
- 练习区块标题右侧是练习步骤的开关；练习卷批改后的卷头也有「标记练习完成」入口。
- 打印练习卷时只输出练习区，页头、锚点条和其它区块会被隐藏。

## 3. 三个学习步骤与课程状态

| 步骤 id | 名称 | 在哪里勾选 |
| --- | --- | --- |
| `words` | 单词 | 单词区块标题右侧的「标记完成」 |
| `grammar` | 语法 | 语法区块标题右侧的「标记完成」 |
| `exercise` | 练习 | 练习区块标题右侧的「标记完成」，或练习卷批改后的「标记练习完成」 |

- 每个区块标题右侧是「标记完成 / 已完成」小开关（`LessonStepToggle`），再点一次取消。
- 课程状态**只在左侧课程列表的下拉框里改**：选「已学习」= 状态 `done` + 三个步骤全部勾上；
  选「学习中」= 状态回 `learning`（保留已有步骤）；选「未学习」= 清除这一课记录。
- 课程状态仍只有 **未学习 / 学习中 / 已学习** 三态，左侧每行显示 **3 个步骤小点**（单词/语法/练习），
  一眼能看出停在哪一步。
- 旧版的 5 步进度在读取时会被丢弃（只认 `words`/`grammar`/`exercise` 三个键），课程状态保留；
  读取逻辑在宿主 `normalizeProgress` 与客户端 `lessonStateOf` 中各做一次归一化。

## 4. 旧存档 / 旧 tab id 的迁移

课程页的「打开某一课并跳到某处」以前用 `openLesson(id, tab)` 传页签 id，现在 tab 表示**锚点**。
旧 id 会自动映射，不会报错：

| 旧 tab id | 新锚点 | 落到哪里 |
| --- | --- | --- |
| `preview` | `text` | 课文 |
| `video` | `video` | 视频 |
| `words` | `words` | 单词 |
| `grammar` | `grammar` | 语法 |
| `homework` | `exercise` | 练习 |
| `exercise` | `exercise` | 练习 |
| `recall` / `review` | 空 | 不滚到特定区块（停在页头） |

- 映射函数是 `LessonAnchorOf`（`src/client/32-lesson-tabs.js`）：未识别的值返回空锚点，只打开课程页。
- 浏览器 `localStorage['dsh-nce/nav/v1']` 里旧的 `tab` 字段、以及其它深链带来的参数，
  都会在打开课程时按上表解析；存档本身不改写，下次操作时自然写成新锚点。
- 课程页记住的是「哪一课 + 哪个锚点」，切去会话/其它插件再回来会恢复。

## 5. 数据与存储

- **课程进度**：宿主 SQLite `~/.dsh/dsh-nce/nce.sqlite` 的 `lessons` 表（`status` + `steps_json`，
  现在只有 `words`/`grammar`/`exercise` 三个键）；页头/区块的勾选和整课状态都走 `lesson/status` op。
- **页面位置**：浏览器 `localStorage['dsh-nce/nav/v1']`（`page` / `lessonId` / `tab`，`tab` 是一次性锚点 id）。
- **滚动位置 / 视频展开**：`dsh-nce/scroll/v1/<视图>`、`dsh-nce/ui/v1/video-open:<课号>`；DSH 切换会话导致面板
  卸载重挂时会自动恢复到离开前的位置（单课详情、左侧课程列表、各页面分别记忆）。
- **练习卷草稿**：`dsh-nce/paper/v1/lesson-<课号>`；**作业清单勾选**：`dsh-nce/homework/v1/lesson-<课号>`。
- 朗读、记忆卡 SRS、翻译卡等其它数据见 [PERSISTENCE.md](PERSISTENCE.md)。

## 6. 错题本（自动收集）

练习卷是错题的来源：批改（AI 老师 / 系统判分 / 手动判对判错）之后，判**错**和**近似**的题会自动写进错题本
（`11-mistake-rows.js` 产出错题行 → `15-mistakes.js` 落 localStorage → `80-mistakes.js` 页面展示）：

- 每题保留：题号、题干、你的答案、参考答案（答案册或 AI 参考写法）、AI 点评、错误/近似标签、时间；
- 按课分组（最近错过的课在前），顶部标签显示待掌握数量；可按 全部 / 错误 / 近似 筛选；
- 「去重做」跳到该课练习卷；「已掌握」从错题本移除；
- 「AI 讲解」让默认模型当英语老师讲这道题（正确答案 / 错在哪里 / 记忆要点），讲解存进该题，可「重新讲解」；
- 历史回填：打开错题本时自动扫描本机练习卷草稿（每份一次），也可点「同步历史练习」重新扫描；
- 改答案/重新批改会自动更新（改对的题自动移出）；清空练习卷时清掉该课的错题。
